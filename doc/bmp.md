# Sample
``` json
{
    "description": "[BlackMagicProbe] NRF52 Controller",
    "type": "bmp",
    "attach": 1,
    "tpwr": true,
    "connect_rst": true,
    "monitor": true,
    "load": ["nrf52_controller/merged.hex"]
}
```

# Arguments
* attach
* tpwr
* connect_rst
* load

a file or a list of files to load

* monitor

    enable RTT view
